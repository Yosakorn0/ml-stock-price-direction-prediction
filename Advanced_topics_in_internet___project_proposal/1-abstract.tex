\begin{center}
    \large{\bf ABSTRACT}
\end{center}

This project presents the design and implementation of an Intelligent Real-Time Financial Data Monitoring and News Aggregation System, demonstrating the practical application of multi-layer Internet protocols and Machine Learning in financial technology. By integrating real-world market data from the Yahoo Finance API and performing automated sentiment analysis on financial news, the platform enables the ingestion, processing, and visualization of live stock market data while analyzing the correlation between news sentiment and price movements.

The system integrates high-frequency WebSocket-based communication for real-time price updates and RESTful APIs for news aggregation and management. These application-layer protocols operate over a secure TCP/IP stack, utilizing TLS encryption to protect sensitive financial data. The architecture incorporates a consolidated backend for data aggregation and a relational database for persistent market history.

The resulting platform demonstrates how layered Internet protocols collectively enable low-latency financial systems, bridging theoretical networking concepts with real-world fintech implementation. This project highlights system modularity, protocol efficiency, and security, providing a professional-grade solution for financial data monitoring.
