\section{Data Source}
The project integrates heterogeneous data from multiple financial and macroeconomic providers to create a holistic predictive feature set:
\begin{itemize}\setlength\itemsep{2pt}
    \item \textbf{Yahoo Finance} -- OHLCV and adjusted close data for a diverse multi-asset portfolio (MSFT, AMZN, GOOGL, GC=F, BTC-USD).
    \item \textbf{Federal Reserve Economic Data (FRED)} -- Macroeconomic variables including interest rates (FEDFUNDS) and inflation.
    \item \textbf{Finnhub API} -- Primary source for real-time company news metadata used for sentiment analysis.
\end{itemize}

\section{Dataset Description and Scientific EDA}
The finalized dataset represents a daily time-series from 2020 to 2026 across five asset classes (Tech, Commodities, Crypto). A critical preliminary step in financial modeling is the assessment of stationarity. We conducted an \textbf{Augmented Dickey-Fuller (ADF)} test to identify the presence of unit roots in the raw price data.

The results, provided in Appendix Table~\ref{tab:adf_results}, confirm that all five asset classes are \textbf{non-stationary} (p-values $> 0.05$). This finding scientifically justifies the transformation of raw prices into daily returns and technical indicators to ensure the model learns from stationary signals, as simple linear regression on non-stationary variables would lead to spurious results.
