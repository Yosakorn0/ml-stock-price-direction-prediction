\chapter{Dataset}

\section{Data Source}
The project integrates heterogeneous data from multiple financial and macroeconomic providers to create a holistic predictive feature set:
\begin{itemize}\setlength\itemsep{2pt}
    \item \textbf{Yahoo Finance} -- OHLCV and adjusted close data for a diverse multi-asset portfolio (MSFT, AMZN, GOOGL, GC=F, BTC-USD).
    \item \textbf{Federal Reserve Economic Data (FRED)} -- Macroeconomic variables including interest rates (FEDFUNDS) and inflation.
    \item \textbf{Finnhub API} -- Primary source for real-time company news metadata used for sentiment analysis.
\end{itemize}

\section{Dataset Description}
The finalized dataset represents a daily time-series from 2020 to 2026 across five asset classes (Tech, Commodities, Crypto). Each observation is a daily snapshot aligned across market price, technical indicators, and news-based sentiment signals. The target variable is binary, representing whether the next trading day's price will close higher than the current day.
