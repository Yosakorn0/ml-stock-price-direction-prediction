\chapter{Code Repository}
The complete implementation of this project is publicly available at:

\begin{center}
\url{https://github.com/Yosakorn0/ml-stock-price-direction-prediction}

\vspace{0.5cm}

\qrcode[height=3cm]{https://github.com/Yosakorn0/ml-stock-price-direction-prediction}
\end{center}

The repository ensures full reproducibility of the data collection and preprocessing pipeline. It includes modular API connectors, feature engineering scripts, validation procedures, and exploratory analysis notebooks. All experiments are version-controlled to maintain transparency, traceability, and research integrity.
